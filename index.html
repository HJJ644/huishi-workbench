① 准备工作：单主与商品

1单主主要通过订单自动拉取：添加订单时填写的单主昵称，会自动保存进单主列表。当然，也可以直接添加单主——点「+ 添加单主」填写联系方式（微信号 / QQ 等）、喜好与标签。
位置：侧边栏 单主列表 → 左卡底部 + 添加单主
2进入「商品仓库」录入你的常卖项目（如 Q版头像、立绘），可加子分类（如「含简单背景 +40」）。之后添加订单时输入商品名会自动带出单价和单位。
位置：侧边栏 商品仓库 → + 添加商品

② 设置费用规则

1「个人设置 → 费用设置」里配置：平台手续费（微信 / 支付宝等按 % 扣）、用途系数（个人 ×1、商用 ×2）、加急费 与 不公开展示费（按系数加收）。
算法：商品小计 =（单价 + 加价）× 用途系数 × 数量 − 优惠
2设置定金（按比例 % 或固定金额，点哪个框用哪种）与废稿比例；其它费用可在「自定义费用」里按 百分比 / 系数 / 固定金额 三种方式新增，下单时一键带出。
填写后记得点左下角 保存费用设置

③ 设计订单模板与小票

1「个人设置 → 订单模板」→「+ 新建模板」：给客户要问的问题逐条添加（问答 / 单选 / 多选 / 日期 / 图片等题型），可勾选必填、设置「逻辑」（选某选项才显示后续题、或跳到指定题）。
编辑器左侧添加问题，右侧实时预览客户看到的表单
2「个人设置 → 小票设置」：10 种视觉款式任选，6 大模块（标题 / 票头 / 商品 / 费用 / 会员 / 票尾）可排序与自定义，支持票头图片、字体与强调色，改完自动保存。

④ 创建订单与收款

1侧边栏「+ 添加订单」：选模板 → 填基本信息 → 添加商品 → 确认费用，右侧实时预览小票，点「创建订单」。必填项没填会弹窗提醒，可选择补填或跳过。
2交稿后进入订单详情，点「标记完成」记录实收；定金、废稿、跑单都在详情页内处理。首页数据卡（待交稿 / 今日到期 / 本月收入）点一下即可跳到对应列表。
订单管理页顶部搜索栏可按时间 / 关键词 / 状态筛查全部历史订单

⑤ 数据安全与备份

1开启「云同步」（个人设置 → 用户资料）后，数据会自动保存到云端，换设备登录同一邮箱即可同步；关闭时数据仅保存在本浏览器，按登录邮箱隔离。也可以随时点右上角「导出数据」下载 JSON 备份文件，在新设备上用「导入数据」恢复。
位置：右上角头像旁 导出数据 / 导入数据；云同步开关在 个人设置 → 用户资料
2建议养成习惯：每次大批量录入后导出一份备份。清除浏览器缓存 / 网站数据会清空本地记录，请务必先备份。

⑥ 常见问题

Q打开网站数据不见了？多半是换了地址 / 端口 / 浏览器，或清了站点数据。用原地址和原邮箱登录试试；不行就用备份导入。
Q修改内容没保存就点走了？会弹窗提醒「保存并离开 / 不保存」，按需选择即可。
Q费用怎么算？商品小计 × 用途系数，再加价急 / 不公开等系数费用；支付平台按比例扣手续费，应付 = 总额 − 优惠 + 附加费。
